# BIR Form 2316 template

`bir_2316_official_2021.pdf` is the BIR Form No. 2316, September 2021 (ENCS),
provided for this HRIS integration from the official BIR download:
https://bir-cdn.bir.gov.ph/local/pdf/2316%20Sep%202021%20ENCS_Final_corrected.pdf

`Bir2316OfficialFormWriter` overlays employee and payroll values on this original
single-page PDF. Do not redraw, crop, rescale, or replace it with the obsolete
2008 HRbliz image. Verify field positions and the BIR's current version before
changing the PDF asset.
